Release notes for ThanCad 0.3.0 "Oberpfaffenhofen"
Tuesday July 26, 2016

1. Source code
--------------
The source code of ThanCad is given as a .zip file for all platforms.
Download the file thancad-0.3.0-source.zip, change to the directory which
was created, and run ThanCad as:
    python thancad.py
Please note that ThanCad was ported to python 3 and will not run in python 2
any more. Thus, depending on your OS, you may have to run ThanCad as:
    python3 thancad.py
ThanCad is known to work in Linux (SuSE), FreeBSD (PCBSD), OpenBSD and 
Windows (XP, 7, 10).
In order to run ThanCad you need to have the following installed in
your computer:

python 3 (programming language)
Pillow for python 3 (Python Image Library fork)
numpy for python3 (Python numeric library)

You also need several modules that come with python (but may not be
available in unusual environments such as cell-phones).


2. Standalone for Linux x86_64 (amd64)
--------------------------------------
If python 3 is not installed in your Linux computer, then ThanCad is given
as a self-complete program. Download thancad-0.3.0-exe.linux-x86_64-3.4.tz,
uncompress it, change to the directory created, and run the executable thancad.
If you want to create a shortcut on your desktop for ThanCad,
an icon is included in the folder you unziped the zip file.


3. Standalone for Windows
--------------------------
For those who are still in windows, a windows installer is included.
Download thancad-0.3.0-win32.msi and run it.
This is for 32bit windows but it also runs fine in 64bit Windows.


4. For all other platforms
--------------------------
For all other platforms, you can run ThanCad from source code as described
previously.
